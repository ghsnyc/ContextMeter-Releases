ContextMeter 1.3.11

Released November 2026

  • Fixed the display freezing after running for a while — the live context percentage, active session and floating window could stop updating (the popover showed "13h ago") until you quit and reopened the app. The app now keeps watching its data file reliably and recovers on its own.
  • Rate limits no longer reset to blank — the 5-hour and 7-day percentages are kept between Claude Code status updates instead of being wiped by an update that carried no rate-limit data.
  • Windows-compatible hooks — the tracking hooks now also run on Windows, and the transcript check no longer rejects valid Windows paths.
