ContextMeter 1.3.9

Released October 2026

  • New Claude models, automatically — when a brand-new Claude model comes out, ContextMeter now sizes its context window from the model's version number (4.6 and newer = 1M tokens), so the gauge is right from the first message instead of showing an impossible percentage until the next update.
  • Settings — the context window override is now labelled "Window size override" (it no longer mentions specific models) and gains a 200K option.
