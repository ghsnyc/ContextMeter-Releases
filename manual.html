ContextMeter

User Manual · Version 1.3 · May 2026

What is ContextMeter?

ContextMeter is a macOS menu bar app that shows you how full your Claude Code context window is — in real time, while you work.

Claude Code gives each conversation a 200,000 token context window. As you work through a session, that window fills up. When it gets full, Claude starts losing track of earlier parts of your conversation. ContextMeter tells you exactly where you are so you can start a new session before things go sideways.

Compatibility

ContextMeter works with Claude Code only. Claude Code is Anthropic’s agentic coding tool — the claude command in your terminal, the Code tab in the Claude Desktop app, and the VS Code extension.

⚠️ Important before purchasing: ContextMeter does not work with the Claude.ai website or the Chat tab in the Claude Desktop app. Those are separate products that don’t use Claude Code’s session system.

System requirement: macOS 15.0 Sequoia or later.

Installation

  1. Download ContextMeter.pkg from ghstudios.lemonsqueezy.com
  2. Double-click the .pkg file
  3. Follow the installer prompts — it installs the app and sets up hooks automatically
  4. Launch ContextMeter from /Applications/ContextMeter.app

ContextMeter is signed and notarized by Apple. macOS will open it without any security prompts.

What the installer does

  • Copies ContextMeter.app to /Applications
  • Copies Python hook scripts to ~/.claude/token_tracker_hooks/
  • Patches ~/.claude/settings.json to register the hooks with Claude Code

No admin password is required. Everything installs to your home folder.

First Launch — License Activation

ContextMeter requires a license key. On first launch, an activation window appears.

  1. Enter your license key (from your purchase receipt)
  2. Click Activate or press Return
  3. ContextMeter verifies the key and unlocks the app

The key is stored securely in your Mac’s Keychain. You only enter it once per machine.

Transferring to a new machine

Each license is valid for a limited number of machines. To move your license:

  1. Open Settings → License
  2. Click Deactivate on this Mac
  3. Install ContextMeter on the new machine and activate with the same key

The Menu Bar Icon

Once installed, ContextMeter lives in your menu bar as a small gauge icon (⊙).

  • No active session: icon shows at rest
  • Active session, context < 60%: icon is normal
  • Active session, context 60–84%: icon turns orange
  • Active session, context ≥ 85%: icon turns red

Click the icon to open the popover.

The Popover

Active session card

When Claude Code is running, you’ll see:

  • Context bar — how full the context window is, with token counts
  • Model — which Claude model is active
  • Source badge — where the session is running (terminal, desktop, or vscode)
  • Token breakdown — input, output, cache read
  • Estimated cost — based on published Anthropic pricing

Usage history

Four time periods — Today, This Week, This Month, All Time:

  • Session count
  • Total tokens (input + output + cache)
  • Estimated cost

Rate Limits

  • 5-hour window and 7-day window usage
  • Real percentages shown for Pro and Max subscribers
  • Turn count fallback for free tier or when data isn’t available yet

Recent Sessions

Last 5 sessions with start time, model, turn count, peak context %, and source. Click the chevron to expand and see the project path.

Float Window

Click Float Window at the bottom of the popover to open a compact always-on-top HUD.

  • Stays visible over all apps, including full-screen
  • Shows the context bar, session info, and rate limits at a glance
  • Drag it anywhere on screen — position is remembered
  • Close it with the × button or toggle it again from the menu bar

Alerts

ContextMeter can send a macOS notification when your context window crosses a threshold.

Default threshold: 60%

To change it: Settings → General → Alerts → Alert threshold

If Claude Code hits a rate limit or billing error during a session, ContextMeter shows it as an orange/red row below the rate limits section.

Settings

General tab

  • Launch at login — start ContextMeter automatically when you log in
  • Alert threshold — percentage at which notifications fire
  • Notify on API errors — on/off toggle
  • Appearance — show icon, show percentage; font size sliders
  • Data retention — how many months of history to keep (3/6/12/24 months)

License tab

Shows your license status, masked key, machine name, and activation date. Use Deactivate on this Mac to free the activation for another machine.

Uninstall tab

  • Remove Hooks — strips ContextMeter from ~/.claude/settings.json and deletes hook scripts. Claude Code continues to work normally.
  • Delete Usage Data — removes the SQLite database and JSON snapshot.

About tab

Check for Updates — manually checks for a new version. ContextMeter also checks automatically once per day.

Privacy

  • No conversation content — hooks only read token counts, never message content
  • Local only — no network calls except for license validation and update checks
  • Your machine only — sessions from other devices are not tracked
  • Secure file permissions — all data files are chmod 600 (readable only by you)

Troubleshooting

Menu bar icon appears but shows no data after starting a session

The hooks may not be installed. Check:

cat ~/.claude/settings.json | grep token_tracker

If nothing appears, go to Settings → General → Hook Status and click Re-install Hooks.

Hook log

tail -f ~/.claude/logs/token_tracker.log

Hooks stop firing after a Claude Code update

Claude Code updates can sometimes reset ~/.claude/settings.json. Go to Settings → General → Hook Status and click Re-install Hooks.

Uninstalling completely

  1. Settings → Uninstall → Remove Hooks
  2. Settings → Uninstall → Delete Usage Data
  3. Settings → License → Deactivate on this Mac
  4. Trash /Applications/ContextMeter.app
