What is ContextMeter?

ContextMeter is a macOS menu bar app that shows you how full your Claude Code context window is — in real time, while you work.

Claude Code gives each conversation a 200,000 token context window. Think of it as Claude’s working memory for your session. As you exchange messages, share code, and have Claude read files, that window fills up. When it fills completely, Claude Code starts a new conversation automatically — and you lose the continuity of your session. ContextMeter tells you exactly where you are so you decide when to start fresh, before Claude loses the thread.

What’s a token? Roughly ¾ of a word, or about 4 characters. “Hello, how are you?” is about 5 tokens. A 500-line Swift file is roughly 3,000–5,000 tokens. The 200k limit is about 150,000 words — enough for a full novel — but complex coding sessions with many large files fill it faster than you might expect.

Compatibility

ContextMeter works with Claude Code only. Claude Code is Anthropic’s agentic coding tool — the claude command in your terminal, the Code tab in the Claude Desktop app, and the VS Code extension.

⚠️ Important before purchasing ContextMeter does not work with the Claude.ai website or the Chat tab in the Claude Desktop app. Those are separate products that don’t use Claude Code’s session system, so there is nothing for ContextMeter to read.

System requirement: macOS 15.0 Sequoia or later.

Installation

  1. Download ContextMeter.pkg from ghstudios.lemonsqueezy.com
  2. Double-click the .pkg file and follow the prompts
  3. Launch ContextMeter from /Applications/ContextMeter.app
  4. Enter your license key when prompted — found in your purchase receipt

ContextMeter is signed and notarized by Apple. macOS opens it without any security prompts.

What the installer does

  • Copies ContextMeter.app to /Applications
  • Copies lightweight Python hook scripts to ~/.claude/token_tracker_hooks/
  • Registers the hooks with Claude Code via ~/.claude/settings.json

No admin password required. Everything installs to your home folder. The hooks use only Python’s standard library — no third-party packages, no network access.

First Launch — License Activation

On first launch an activation window appears. Enter your license key (from your purchase receipt) and click Activate. The key is stored in your Mac’s Keychain — you only enter it once per machine.

Transferring to a new machine

  1. Open Settings → License → Deactivate on this Mac
  2. Install ContextMeter on the new machine and activate with the same key

ContextMeter lives in your menu bar as a small gauge icon. When a session is active it shows the current context percentage next to the icon.

The Popover & Float Window

Alert banner

When context crosses your alert threshold (default 60%), an orange banner appears at the top of the popover: “Approaching context limit — consider starting a new session.”

When should you start a new session? 70–80% is the sweet spot. At that point Claude still has strong recall of everything in your session. Wait until 95%+ and Claude may already be losing context of decisions made early in your conversation — you might notice it repeating questions or forgetting constraints you set at the start.

Float window

Click Float Window at the bottom of the popover to open a compact always-on-top HUD. It stays visible over all apps including full-screen. Drag it anywhere on screen — its position is remembered between launches. Close it with the × button or click Float Window again to toggle it off.

Understanding Your Numbers

This section explains what each number means and how it affects you as a Claude Code user.

Context window — the progress bar

The bar and percentage show how much of Claude’s 200,000-token working memory is used in the current session. It accumulates everything: your messages, Claude’s responses, file contents, tool call results, and system context.

ColorRangeWhat it means
Green0–59%Plenty of headroom. Work normally.
Orange60–84%Getting full. Wrap up your current task and plan a stopping point.
Red85%+Nearly full. Start a new session — Claude may already be missing early context.
Why context fills fast in coding sessions When Claude reads your project files, edits code, and runs tools, every result gets added to the context window. A session that reads a 500-line file 10 times and generates 2,000 lines of output can use 60%+ of the window in a single afternoon. This is normal — ContextMeter just makes it visible so you’re never surprised.

Token breakdown

Tokens are the fundamental units Claude uses to process everything. Every session accumulates three types, shown in the active session card and float window:

Input
Tokens in your messages to Claude — your prompts, questions, and any code or text you paste directly into the chat. This is typically the smallest number by far. If you’re sending short prompts and letting Claude do the heavy lifting, Input stays very low.
Output
Tokens Claude generates in its responses — code, explanations, analysis, and tool call results. This is almost always your biggest cost driver. Output tokens are priced higher than input tokens (roughly 3–5× more per million on most models). Sessions that generate long code files or detailed explanations will show a large Output number.
Cache Read
Tokens served from Anthropic’s prompt cache — large, repeated context like system prompts and project files get cached automatically after the first turn. Each subsequent turn reads those files from cache instead of re-processing them. Cache read tokens cost about 90% less than regular input tokens — so a very large Cache number is actually good news for your bill.
Real-world example — reading the numbers in the screenshot above That session shows Input: 116 • Output: 50k • Cache: 8.8M • Cost: ~$4.62.
  • Input 116 — very short prompts were sent each turn
  • Output 50,000 — Claude generated a substantial amount of code and explanations over 95 turns
  • Cache 8,800,000 — Claude re-read the same project files over and over, but served them from Anthropic’s cache at ~$0.03/million instead of the full input price of ~$3/million
  • Cost ~$4.62 — for 8.8 million tokens processed, this is efficient. If those cache tokens had been billed as regular input, the cost would have been roughly 10× higher.
The cache is doing its job. This is Claude Code working as designed.

Estimated cost

The ~$X.XX figure applies Anthropic’s published per-token pricing for the active model to your Input, Output, and Cache Read totals. The tilde (~) means approximately — actual charges on your Anthropic bill may differ slightly due to rounding.

The This month figure (below the usage history tabs) is your estimated total Claude Code spend across all sessions on this machine for the current calendar month.

Cost rule of thumb Output tokens are the most expensive type. If your monthly cost feels high, look at your Output totals — long code generation sessions are the main driver. Cache Read volume has almost no impact on cost, regardless of how large it gets.

Turns

Each time you send a message and Claude responds = 1 turn. Tool calls Claude makes within a single response (reading a file, running a command, editing code) don’t add extra turns — they’re part of that response. A high turn count (50+) indicates an extended, productive working session.

Source badge

Shows where your Claude Code session is running:

  • terminal — the claude CLI in your Terminal app or iTerm
  • desktop — the Code tab in the Claude Desktop app
  • vscode — the Claude Code extension inside VS Code

Usage History

Four time periods — Today, This Week, This Month, All Time — each showing total sessions, total tokens (Input + Output + Cache combined), and estimated cost.

Why does Today show 0 tokens while a session is active? ContextMeter writes session totals to its database when a session ends, not continuously. The active session card always shows live real-time values, but the usage history totals only update once the session finishes. This prevents double-counting. Once you end your Claude Code session, the numbers update within seconds.

Rate Limits

Claude Code enforces usage limits on rolling time windows. ContextMeter reads these from Claude Code’s status line so you can see how close you are before hitting a wall mid-session.

5-hour window

A rolling 5-hour cap on tool calls. If you hit it, Claude Code pauses and tells you when the window resets. Resets automatically — no action needed from you.

7-day window

A rolling 7-day (weekly) cap. Pro and Max subscribers get higher limits than free accounts. You’ll almost never hit this unless you’re running intensive automated sessions.

Why the 5-hour count might show 0

If you haven’t used Claude Code in the last 5 hours, the 5-hour count shows 0 — even if you’ve had a busy day. The 7-day count shows your full week’s cumulative usage, which will be much higher. Seeing “0 tool calls” in the 5-hour window alongside 1,000+ in the 7-day window is completely normal.

“Activity only · Pro/Max for %”

The percentage-based rate limit display requires Anthropic to expose your plan’s cap size — they only do this for Pro and Max subscribers. On a free account, ContextMeter shows raw tool call counts instead.

Recent Sessions

The last 5 completed Claude Code sessions, each showing start time, model, turn count, peak context %, and source badge. Click the chevron (›) to expand any session and see the project folder path.

Peak context % is the highest context percentage reached during that session — color-coded using the same green / orange / red thresholds as the live bar.

Why do older sessions show “0% peak” or “unknown”? Sessions that ran before ContextMeter was fully installed didn’t have peak context or model data recorded at the time. They show “—” and “0%” as placeholders. All new sessions going forward record the full data set automatically.

Alerts

ContextMeter sends a macOS notification when your context crosses your configured threshold.

Default threshold: 60% — change it at Settings → General → Alerts → Alert threshold

A notification fires once per crossing. You won’t be notified repeatedly if context stays high for a long session.

API error notifications

If Claude Code hits a rate limit or billing error mid-session, ContextMeter shows it as a colored row below the rate limits section and fires a notification once per new error. Toggle this off at Settings → General → Alerts → Notify on API errors.

Settings

General tab

  • Launch at login — start ContextMeter automatically when you log in
  • Alert threshold — % at which notifications fire (default 60%)
  • Notify on API errors — on/off toggle for rate limit and billing error alerts
  • Appearance — show icon only or icon + percentage; font size sliders for menu bar, popover, and float window independently
  • Data retention — how many months of session history to keep (3, 6, 12, or 24 months). Data older than this is pruned automatically at startup.
  • Purge now — immediately deletes data older than your retention setting
  • Hook status — shows whether each hook script is installed and up to date. Click Re-install Hooks to restore them if missing.

API Key tab

Optional. If you add an Anthropic API key, ContextMeter can validate it and show available models. Not required for any core functionality.

License tab

Shows your license status, masked key, machine name, and activation date. Use Deactivate on this Mac to release this machine’s activation slot.

Uninstall tab

  • Remove Hooks — strips ContextMeter from ~/.claude/settings.json and deletes hook scripts. Claude Code keeps working normally.
  • Delete Usage Data — permanently removes the SQLite database and JSON snapshot.

About — Check for Updates

ContextMeter checks for updates automatically once per day via Sparkle. When available, a dialog appears with release notes and an Install button — no manual download needed.

Privacy

  • No conversation content — hooks read only token counts from Claude Code’s usage metadata. Your message text and code are never read or stored.
  • Local only — no network calls except license validation (at launch) and update checks (daily)
  • Your machine only — sessions from other devices are not tracked
  • Secure file permissions — all data files are chmod 600 (readable only by your user account)
  • Offline capable — works without internet; a 45-day grace period applies if the license server is unreachable

Troubleshooting

Menu bar shows but no data after starting a session

Go to Settings → General → Hook Status → Re-install Hooks. Or verify manually:

cat ~/.claude/settings.json | grep token_tracker

Check the hook log

tail -f ~/.claude/logs/token_tracker.log

Hooks stop working after a Claude Code update

Claude Code updates can reset ~/.claude/settings.json. Go to Settings → General → Hook Status → Re-install Hooks.

Usage history shows 0 during an active session

Expected — totals are written when a session ends. The active session card shows live data. End the Claude Code session and the history updates within seconds.
